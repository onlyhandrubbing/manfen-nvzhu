第一次使用，先設定金鑰

這把金鑰讓這個頁面可以幫你改網站上的商品。只會存在這支手機（或這台電腦）的瀏覽器裡，不會給任何人。

  1. 用手機或電腦開 GitHub 金鑰設定頁，登入你的 GitHub。
  2. Token name 填 滿分女主管理，Expiration 選 1 year。
  3. Repository access 選 Only select repositories，選 manfen-nvzhu。
  4. Permissions 裡把 Contents 設成 Read and write；想用「立即檢查賣貨便」按鈕的話，Actions 也設成 Read and write。
  5. 按 Generate token，複製 github_pat_ 開頭那串，貼到下面。
